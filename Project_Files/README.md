# Project Files & Operational Resources

This directory organizes all operational, development, testing, configuration, and documentation resources for the hospitality platform.

## Directory Structure

- `Chrome_Extension/`: Browser extension for review automation and Google Maps integration.
- `Scripts/`: Operational tooling for backups, provisioning, releases, and browser acceptance.
- `Tests/`: Automated unit, integration, and security test suites.
- `Configs/`: Pipeline and environment configuration templates.
- `Docker/`: Container definitions and compose files.
- `Docs/`: System architecture, API specifications, and workflow documentation.
- `Reports/`: Audit reports, research benchmarks, and model performance evaluations.
- `Artifacts/`: Build and presentation artifacts.
- `Releases/`: Versioned release archives and cryptographic SHA-256 manifests.
- `Data/`: Local SQLite development databases and isolated tenant document storage.
- `Logs/`: System and application execution logs.
- `Other_Documentation/`: Historical notes, task logs, and reference presentations.
