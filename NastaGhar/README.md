# NastaGhar Frontend & Review System

This directory contains the customer-facing Review Assistant experience, restaurant ambience presentation, and restaurant owner portal.

## Structure

```text

├── frontend/
│   ├── src/

│   │   │   ├── CustomerReview.jsx
│   │   │   ├── OwnerPortal.jsx
│   │   │   ├── RestaurantWorld.jsx
│   │   │   ├── RestaurantWorld.css
│   │   │   └── NastaGharRestaurantScene.jsx
│   │   ├── lib/

│   │   ├── App.jsx

├── assets/
│   ├── darshan-host.png
│   ├── scene-phone.webp
│   └── scene-wide.webp
└── README.md
```

## Running NastaGhar Frontend

```bash
cd NastaGhar/frontend
npm run dev
# Running on http://127.0.0.1:5173
```
